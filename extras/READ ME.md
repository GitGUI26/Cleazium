# Cleazium extras

Two small loader pages for hosting Cleazium somewhere else.

- **Normal Single File.html** — a simple loader that pulls in your Cleazium site.
- **Stealth Single File.html** — loads Cleazium behind a placeholder page, with an option to open it in an about:blank tab.

Before using either one, open the file and replace `https://YOUR-CLEAZIUM-SITE.example/` with the address where you host Cleazium (keep the trailing slash).
